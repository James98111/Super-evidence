OPEN METHODOLOGY

How this prototype treats data

  1. Issuer first: super-fund public pages and documents are the preferred evidence for fund-specific facts.
  2. APRA cross-check: regulatory data is kept separately and used for peer and methodology consistency.
  3. No false precision: a mixed asset bucket is not converted into a precise standardised growth percentage unless underlying detail supports it.
  4. No silent substitution: secondary-source values are labelled as such until the issuer value is directly extracted.
  5. No overwriting: historical values remain date-stamped and queryable.

The production architecture also separates Fund → Product → Investment Menu → Investment Option → Investment Pathway so fees and returns are not attached to the wrong level.
